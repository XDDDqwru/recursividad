# recursividad
Un factorial es el resultado de multiplicar un número entero positivo por todos los números enteros que son menores que él hasta llegar al uno
La recursividad es un proceso que se repite al aplicarse a sí mismo. En programación y matemáticas, significa que una función se llama dentro de su propio código para resolver un problema paso a paso. Se usa para dividir un problema grande en partes más pequeñas y fáciles de resolve
